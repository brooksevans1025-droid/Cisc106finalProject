ABOUT PONYTAIL
--------------
Ponytail is a plugin for Claude Code (the AI coding assistant used for this
project). It makes the assistant act like a "lazy senior developer": solve
the whole problem with the least new code. In practice it:
- skips features and options nobody asked for,
- reuses what already exists (the project's code, the standard library,
  installed packages) before writing anything new,
- never adds a package for a few lines of code,
- still requires tests for new logic and never cuts input checks, error
  handling, security or accessibility,
- ends each reply with what was skipped or not checked.
It has levels: lite, full (default) and ultra. Ultra, used here, also
questions the request itself before building. It also has extra commands,
such as /ponytail:ponytail-review, which reviews a change and lists numbered
findings to fix.

The responses below are the assistant's replies, with the code left out.
Questions the assistant asked mid-task, and the answers, are included.
